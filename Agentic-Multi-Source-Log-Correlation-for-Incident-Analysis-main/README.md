# Agentic Multi-Source Log Correlation for Incident Analysis
An agentic AI system that correlates logs from multiple sources to detect incidents, identify relevant events, and assist with root-cause analysis. It uses LLM-based reasoning to generate structured incident insights and actionable troubleshooting information.
# Key Features
- Multi-source log correlation
- Incident and anomaly detection
- LLM-assisted root-cause analysis
- Automated incident reporting
- Evaluation and testing of AI-generated analysis
# Tech Stack
Python • LLM • AI Agents • Log Analysis • RAG • FastAPI
